### 学生考试考场抽签系统

面向学校考组的考生考场与座位随机抽签系统，提供浏览器端管理界面和 Windows 桌面端。

- 基于 JWT 的角色权限隔离，考组账号仅能访问所属学校与考组的数据
- 座位随机分配，对报名号、考场号与座位号施加唯一性约束，避免重复分配
- 支持 Vue Web 前端与 Tauri Windows MSI 桌面应用双端打包

`Python` `FastAPI` `SQLAlchemy` `Vue 3` `Vite` `Rust` `Tauri` `MySQL`

### HarmonyOS 应用实践

鸿蒙原生应用开发练习，使用 ArkTS 与 ArkUI 声明式开发范式。

`ArkTS` `HarmonyOS` `ArkUI`
